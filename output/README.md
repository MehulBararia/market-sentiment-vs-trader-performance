# Output Folder

This folder is generated by running:

```powershell
python main.py
```

Generated charts are saved in:

- `output/charts/`

Generated tables are saved in:

- `output/tables/`

The final Markdown report is saved as:

- `output/final_summary.md`

Most generated outputs are ignored by Git so the repository stays lightweight. Re-run the pipeline to regenerate them.
