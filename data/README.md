# Data Folder

Place the input CSV files here before running the project.

Expected files for the current setup:

- `fear_greed_index.csv`
- `historical_data.csv`

The code also supports similar filenames containing keywords such as:

- `fear`, `greed`, `fg`
- `historical`, `trades`, `hyperliquid`, `hl`

Raw datasets are ignored by Git because they may be large or private. Keep `data/.gitkeep` so the folder exists after cloning.
